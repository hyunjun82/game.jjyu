현재 폴더의 manifest.json 을 Read 로 읽어라. posts 배열의 각 글은 한국 모바일 게임 공식 라운지의 "쿠폰" 글이고, 본문 글자에서는 쿠폰 코드가 나오지 않았다. 코드가 이미지 안에 있을 수 있다.

각 글의 images 에 적힌 이미지 파일을 하나씩 Read 로 직접 보고, 게임 안에서 입력하는 쿠폰 코드(쿠폰 코드·교환 코드·기프트 코드·선물 코드·CDK 라벨이 붙은 것)를 찾아라.

규칙
- 이미지에 실제로 보이는 코드만 적는다. 추측하지 않는다.
- 글자 하나라도 확실하지 않으면(0과 O, 1과 I와 l, 5와 S, 8과 B 등) 그 코드는 적지 않는다.
- 할인 쿠폰, 결제 금액 할인, 웹상점 할인 코드, URL, 날짜, 아이템 이름, 게임 이름은 코드가 아니다.
- 퀴즈 정답을 넣어야 완성되는 반쪽 코드는 적지 않는다.
- 사용 기한이 이미지에 보이면 마지막 날을 YYYY-MM-DD 로 적는다. 연도가 없으면 글의 date 연도를 쓴다. 안 보이면 null.

모든 글을 다 본 뒤, 현재 폴더에 result.json 을 Write 로 만든다. 형식은 다음과 같고, 코드가 없는 글도 codes 를 빈 배열로 넣는다.
[{"feedId": 123, "codes": [{"code": "DOE1STYEAR", "expiry": null}]}]

result.json 을 쓴 뒤 "완료" 한 단어만 출력하고 끝낸다.
